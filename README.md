# Examination Seating Allocation and Conflict Detection

A C++ terminal-based project that assigns students to examination seats using Greedy and Backtracking algorithms and checks for seating conflicts.

## Features

- Enter and store hall details
- Enter student details
- Allocate seats using Greedy
- Check seating conflicts
- Display allocation results
- Display Seating Map
- Save and Load Student and Hall details through file handling

## Requirements

- A C++ compiler supporting C++17
- A terminal or command prompt

## How to run

Compile the project:

```bash
g++ main.cpp greedy.cpp backtracking.cpp conflicts.cpp -o main
```

Run on Windows:

```powershell
.\main.exe
```

Run on Linux or macOS:

```bash
./main
```

Follow the menu displayed in the terminal to enter halls and students, run the algorithms, and view the results.
